Types of Machine Learning
Overview
Machine Learning systems can be classified using three independent
criteria:
1. Type of supervision: Supervised, Unsupervised, Semi-Supervised,
   and Reinforcement Learning.
2. How the model learns from incoming data: Batch Learning and
   Online Learning.
3. How the system generalizes to unseen examples: Instance-Based
   Learning and Model-Based Learning.
These categories are not mutually exclusive. A single system can
belong to one category from each criterion. For example, a spam filter
may be a supervised, online, model-based learning system.

# Types of Machine Learning

## 1. Based on Supervision

### A. Supervised Learning

Supervised Learning mein model labelled data se learn karta hai.

**Example:** House price prediction.

- **Features (X):** House size, location, bedrooms
- **Target (y):** House price

### B. Unsupervised Learning

Isme training data ke saath target labels nahi diye jaate.

**Common algorithms:**
- K-Means
- DBSCAN
- PCA
